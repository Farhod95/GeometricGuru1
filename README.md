# Geometrik Shakllar Kalkulyatori (C#)

Ushbu konsol dasturi turli xil geometrik shakllarning o'lchamlarini (yuzi, perimetri, balandligi va h.k.) hisoblash uchun mo'ljallangan. Dastur o'zbek tilida muloqot qiladi va foydalanuvchi uchun qulay interfeysga ega.

## ✨ Imkoniyatlar

Dastur quyidagi shakllar bilan ishlay oladi:
* **Doira:** Diametr, uzunlik va yuzani hisoblash.
* **Uchburchak:** Ixtiyoriy uchburchakning perimetri va yuzasini (Geron formulasi orqali) hisoblash.
* **Teng tomonli uchburchak:** Perimetr, balandlik va yuzani hisoblash.
* **Kvadrat:** Perimetr va yuzani hisoblash.
* **To'g'ri burchakli to'rtburchak:** Perimetr va yuzani hisoblash.

## 🚀 Texnologiyalar
* **Til:** C#
* **Platforma:** .NET Console Application

## 🛠 Ishlatish tartibi

1.  Loyihani yuklab oling yoki klonlang:
    ```bash
    git clone [https://github.com/foydalanuvchi_nomi/loyiha_nomi.git](https://github.com/foydalanuvchi_nomi/loyiha_nomi.git)
    ```
2.  Loyihani Visual Studio yoki VS Code orqali oching.
3.  Dasturni ishga tushiring (`F5`).
4.  Menyudan kerakli shakl harfini kiriting:
    * `D` - Doira
    * `W` - Uchburchak
    * `U` - Teng tomonli uchburchak
    * `K` - Kvadrat
    * `T` - To'g'ri burchakli to'rtburchak
5.  O'lchamlarni kiriting va natijani oling.

## 📝 Kodning o'ziga xosligi
* **Xatoliklar nazorati:** Noto'g'ri son yoki amal kiritilganda dastur foydalanuvchini ogohlantiradi.
* **Takrorlash tizimi:** Har bir hisoblashdan so'ng dasturni qayta ishga tushirish imkoniyati mavjud (`yes/no`).
* **Matematik aniqlik:** Hisob-kitoblar uchun `Math` kutubxonasidan foydalanilgan.
